## Type

Headings + logo + pull quotes: **Cormorant Garamond**
- H1: weight 500, clamp 2.4rem–4.4rem, line-height 1.12
- H2: weight 500, clamp 2.0rem–3.15rem, line-height 1.12
- H3: weight 500, 1.55rem
- Logo: 1.55rem, weight 600
- Pull quote: italic, clamp 1.6rem–2.15rem, line-height 1.35
- Block quote: italic, 1.45rem, line-height 1.4

Body: **Source Sans 3**
- Body: 1.12rem, weight 400, line-height 1.7, color ink-soft
- Nav / buttons: 0.95rem
- Kicker / eyebrow: 0.72–0.75rem, weight 600, uppercase, letter-spacing 0.16–0.18em

Google Fonts:
`Cormorant Garamond` (400,500,600,700 + italic 400,500)
`Source Sans 3` (300,400,500,600 + italic 400)
